# Assets

## Logo institucional

Para mostrar el logo oficial de la Universidad de los Andes en la portada (`index.html` en la raíz),
coloca el archivo aquí con uno de estos nombres exactos:

- `uniandes-logo.svg` (preferido — escala sin perder calidad)
- `uniandes-logo.png` (alternativa)

El index intentará cargar primero el `.svg` y luego el `.png`. Si ninguno existe, mostrará un
escudo decorativo neutral.

Descarga el logo oficial desde el centro de identidad visual de Uniandes (necesitas usuario activo).
